# 舒尔特方格自动点击器 · Schulte Grid Auto Clicker

一款 Windows 桌面工具，**自动完成舒尔特方格训练**。  
程序识别屏幕上的 5×5 数字方格，按 **1 → 2 → … → 25** 的顺序自动点击。  
点击节奏**模拟真人**——间隔随机、速度有快有慢、中间会随机"卡顿"一次。

## 功能特点

- **模板匹配识别**：无需 OCR，**速度快、准确率高**（25 格 < 50ms）
- **三种鼠标模式**：
  - **瞬移**：鼠标直接跳到目标位置（默认，最快）
  - **平滑移动**：直线匀速滑动 200~400ms
  - **人类模拟**：贝塞尔曲线 + 速度变化 + 微小抖动，**最像真人**
- **真人节奏**：相邻点击间隔随机，**中间随机插入一次"大停顿"**
- **总时长可调**：整套点击锁定在指定秒数内（默认 ~13 秒）
- **多字体模板**：支持为不同字体准备多套模板（`matchTemplates/` 文件夹）
- **双版本自动切换**：Web 界面 + tkinter 兼容界面，**自动降级**
- **自定义图标**：exe 与窗口图标均可替换
- **邀请码保护**：`< 20 秒` 目标时长需邀请码（可选功能）

## 快速开始

### 方式 1：下载 exe（推荐）

从 [Releases](https://github.com/clocktool/Schulte/releases) 下载最新的 `SchulteAutoClicker.exe`，**双击运行**。

> 系统要求：Windows 10 / 11（64 位），建议屏幕缩放保持 **100%**，否则坐标可能偏移。

### 方式 2：从源码运行

```bash
git clone https://github.com/clocktool/Schulte.git
cd Schulte
pip install -r requirements.txt
python launcher.py
```

## 使用步骤

1. 打开**舒尔特方格**页面/程序，让 25 个数字完整显示在屏幕上
2. 打开本工具，点 **"重新选区"**
3. 屏幕变暗后，**按住鼠标左键拖动**，框住整个 5×5 方格区域（松手即完成）
4. 调整参数（默认可用），点 **"开始点击"**
5. **3 秒内**切换到舒尔特方格窗口
6. 程序自动完成识别 + 点击

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| 起始等待（秒） | 3 | 点"开始点击"后留给你切窗口的时间 |
| 目标总时长（秒） | 20 | 整套点击的目标耗时 |
| 最快间隔（秒） | 0.18 | 相邻点击之间的最小间隔 |
| 最慢间隔（秒） | 0.55 | 相邻点击之间的最大间隔 |
| 大停顿最小（秒） | 1.5 | 一次"卡顿"的最小时长 |
| 大停顿最大（秒） | 2.5 | 一次"卡顿"的最大时长 |
| 格子边缘收缩比例 | 0.15 | 识别时向内收缩比例，避免边框干扰 |
| 匹配阈值（score <） | 0.15 | 数字识别的相似度阈值，越小越严格 |
| 排序方向 | 从小到大 | 也可改为从大到小 |
| 鼠标模式 | 瞬移 | 瞬移 / 平滑移动 / 人类模拟 |
| 人类模拟抖动（像素） | 2 | 人类模拟的抖动幅度 |
| 点击抖动（像素） | 1 | 每次点击位置的随机偏移 |

## 自定义模板

内置了 25 张标准数字模板（`templates/1.png` ~ `25.png`）。

如果目标网站的字体不同，可以**自定义模板**：

1. 在 exe 同级新建 `matchTemplates/` 文件夹
2. 里面可以有两种结构：

**单一字体**：

```text
matchTemplates/
├── 1.png
├── 2.png
└── ...
```

**多字体（推荐）**：

```text
matchTemplates/
├── 思源黑体/
│   ├── 1.png ~ 25.png
├── 微软雅黑/
│   ├── 1.png ~ 25.png
└── 仿宋/
    └── 1.png ~ 25.png
```

3. 程序启动时会**自动扫描**并列出可用的模板包
4. 在界面上选择对应的模板包即可

> 制作模板：从目标网站上**截图单个数字**，裁剪后保存为 `1.png` 到 `25.png`。

## 常见问题

### Q1：识别不全 / 识别错？

- **重新选区**，确保框住整个 5×5 方格
- 如果字不是蓝色，可能需要修改 `template_match.py` 里的颜色过滤
- 或**换一套模板**（见上文"自定义模板"）

### Q2：点击位置偏移？

- 检查 **Windows 显示缩放**：设置 → 系统 → 显示 → 缩放 → 改为 **100%**
- 或**重新选区**（目标窗口位置变了）

### Q3：点击无效？

- 目标程序以**管理员身份**运行时，本程序也需要**以管理员身份运行**
- 反之亦然（两者权限要一致）

### Q4：目标总时长 < 20 秒弹出邀请码？

这是**防止工具泛滥导致异常成绩**的设计。如需使用短时长，请联系管理员获取邀请码。

### Q5：WebView2 相关报错？

Windows 11 自带，Windows 10 多数已装。如果没装，程序会**自动降级到 tkinter 界面**。

### Q6：杀毒软件报警？

PyInstaller 打包的程序**常被误报**，这是行业通病。**加白名单**即可。

## 原理简述

1. **截屏**：按选区坐标，从屏幕上截取目标区域
2. **颜色分离**：提取蓝色数字，转成白底黑字
3. **5×5 切分**：将区域均匀切成 25 个格子
4. **模板匹配**：每个格子图像与 25 张数字模板逐一比对，取最相似的
5. **排序**：按数字大小排序，得到点击顺序
6. **模拟点击**：按真人节奏依次点击，带随机间隔和一次大停顿
